# Fit Studio

Курсовая работа: мобильное приложение администратора фитнес-клуба.

Приложение на Kotlin хранит данные в локальной базе SQLite через Room. Файл базы `fitstudio.db` создаётся на телефоне при первом запуске. Отдельный сервер не нужен.

## Запуск

1. Открыть в Android Studio папку `android`.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или телефоне с Android 8.0 и выше.

Разделы приложения: «Клиенты» и «Расписание».
